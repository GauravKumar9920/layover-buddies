# Detour — Outreach & Content Templates

Ready-to-personalise copy for the 90-day "Founding Travelers" pipeline (see `../strategy/03-marketing-pipeline-90-days.md`). Everything here is a starting point — **always personalise the first line** (a generic blast gets ignored or, on Reddit, gets you banned).

| File | Use it for | Pipeline week |
|---|---|---|
| `pr-pitch-indian-outlets.md` | First PR wave — 5 Indian outlets | Week 4 |
| `pr-pitch-international.md` | Second PR wave — points/layover blogs | Week 7 |
| `creator-pitch.md` | Offer a free detour to a creator with a BOM layover | Week 5 |
| `reddit-answer-template.md` | Answering layover threads (r/travel, r/IndiaTravel, etc.) | Weeks 3+ |
| `review-ask-whatsapp.md` | Same-day review request after a completed detour | Weeks 9+ |
| `newsletter-email-1.md` | First email to the list — cheat sheet + founding-traveler invite | Week 6 |
| `newsletter-email-2.md` | Second email — first founding-traveler stories | Week 11 |

**Golden rules**
1. Personalise line one. Reference their actual work/subreddit/recent piece.
2. On Reddit/forums: be useful first, disclose once, sell never. (See that template.)
3. Never fake numbers or reviews. "We're new, here's our first real story" beats invented social proof.
4. One ask per message. Make the yes easy.
