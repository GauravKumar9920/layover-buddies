# UI Mockups & Design Files

## Purpose
Store all wireframes, prototypes, and high-fidelity mockups for the website, web application, and mobile apps. This folder serves as the design reference for development teams.

## Contents
- Website Mockups (landing page, about, features pages)
- Web App Screens (authentication, search, booking, messaging)
- Mobile App Screens (iOS and Android)
- User Flow Diagrams
- Wireframes (low-fidelity layouts)
- Interactive Prototypes

- [ ] All screens designed at 1x, 2x scales
- [ ] Responsive versions (desktop, tablet, mobile)
- [ ] Interactive states (hover, focus, active)
- [ ] Loading states
- [ ] Error states
- [ ] Empty states
- [ ] Dark mode variants (optional)
- [ ] Accessibility annotations
- [ ] Component specifications
- [ ] Spacing & sizing guide
- [ ] Font/color specifications
