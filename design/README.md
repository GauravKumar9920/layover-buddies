# Design Assets

## Purpose
Centralized repository for all brand identity, UI/UX mockups, design system components, and marketing creative assets. Maintain consistency across all platforms (website, web app, mobile, social media).

## Folder Structure

### brand/
Brand guidelines, logo files, color palette, typography, icons, and visual identity standards.

### ui-mockups/
Wireframes, prototypes, and high-fidelity designs for website, web app, and mobile applications.

### marketing/
Social media templates, promotional graphics, ad creatives, email templates, and campaign assets.

## Design Tools Recommended
- **Design**: Figma (collaborative, cloud-based)
- **Prototyping**: Figma, Framer, Protopie
- **Asset Optimization**: Figma, Sketch
- **Icons**: Figma community, Heroicons, Feather Icons
- **Stock Images**: Unsplash, Pexels, Pixabay
- **Color Palette**: Coolors.co, Adobe Color

## Responsive Design Breakpoints
- Mobile: 375px (iPhone SE)
- Tablet: 768px (iPad)
- Desktop: 1024px (standard)
- Large Desktop: 1440px (wide screens)

## Accessibility Standards
- [ ] WCAG 2.1 Level AA compliance
- [ ] Color contrast ratios (4.5:1 for text)
- [ ] Focus states visible on all interactive elements
- [ ] Keyboard navigation support
- [ ] Alt text for all images
- [ ] Semantic HTML structure

## Asset Export Standards
- **Web**: PNG/SVG at 1x, 2x scales
- **Mobile**: PNG/SVG for iOS and Android
- **Social**: Square (1:1), landscape (16:9), story (9:16)
- **Print**: PDF, 300 DPI
