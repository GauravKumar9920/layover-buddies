# Brand Assets

## Purpose
Store all brand identity materials including logo files, color specifications, typography settings, and icon assets. This is your single source of truth for maintaining consistent visual identity across all platforms.

## Contents
- Logo Files (PNG, SVG, AI formats at various sizes)
  - Primary Logo
  - Secondary Logo
  - Logo Mark (icon only)
  - Monochrome Version
  
- Color Palette
  - Primary Colors
  - Secondary Colors
  - Neutral Colors (grays, whites)
  - Status Colors (success, error, warning, info)
  
- Typography
  - Primary Font Files (WOFF, TTF, OTF)
  - Font Weights & Sizes
  - Line Heights & Letter Spacing
  
- Icon Set
  - Common UI Icons (search, heart, map, message, etc.)
  - SVG Format for scalability
  
- Style Guide Document
  - Logo usage & clearance space
  - Color specifications (hex, RGB, HSL)
  - Font specifications
  - Tone of voice guidelines

## Exporting for Different Platforms
- **Web**: SVG (scalable), PNG (2x for retina)
- **iOS**: PDF, PNG (1x, 2x, 3x)
- **Android**: PNG (ldpi, mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi)
- **Print**: High-resolution PDF or TIFF

## Tools for Asset Management
- **Figma**: Design system and brand kit
- **Storage**: Google Drive, Dropbox, or GitHub (version control)
- **Font Hosting**: Google Fonts (free), Adobe Fonts (paid)

## Versioning
Keep track of brand asset changes:
- v1.0 - Initial brand identity
- v1.1 - Logo refinement
- v2.0 - Major rebrand (if needed)

Document changes and reasons for updates.
