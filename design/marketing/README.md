## Social Media Specs

### Instagram
- **Posts**: 1080x1080px (1:1 square)
- **Stories**: 1080x1920px (9:16 vertical)
- **Reels**: 1080x1920px (9:16 vertical)
- **Recommended file format**: PNG or JPG

### Facebook
- **Posts**: 1200x628px (1.91:1)
- **Cover Photo**: 820x312px (2.63:1)
- **Stories**: 1080x1920px (9:16 vertical)

### LinkedIn
- **Posts**: 1200x627px (1.91:1)
- **Articles**: 1200x627px for thumbnail

### Twitter/X
- **Posts**: 1024x512px (2:1)
- **Header**: 1500x500px

### TikTok
- **Videos**: 1080x1920px (9:16 vertical)
- **Text overlay**: Sans-serif, contrasting colors

## Ad Creative Best Practices
- **Headlines**: Clear, benefit-focused (50-60 chars)
- **Copy**: Action-oriented, short sentences
- **CTAs**: Strong verbs (Book, Discover, Join, Start)
- **Visuals**: High-quality, authentic photos
- **Colors**: Brand consistent, high contrast
- **Text-to-Image Ratio**: <20% for Facebook Ads

## Campaign Assets Naming Convention
```
[Platform]_[CampaignName]_[Format]_[Version]
Example: instagram_summer-sale_post_v1.0.png
```
