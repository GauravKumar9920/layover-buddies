# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's **Report a vulnerability** option in this repository's Security
tab so the report and any follow-up discussion remain private. If that option
is unavailable, email [admin@detourtrips.com](mailto:admin@detourtrips.com)
with:

- the affected component and version or commit;
- steps to reproduce the issue;
- the likely impact; and
- any suggested mitigation, if known.

Do not include live credentials, personal data, or exploit payloads beyond
what is necessary to reproduce the issue safely.

We will acknowledge reports as soon as practical, investigate them, and share
status updates through the private report. Please allow time for a fix to be
prepared before publishing details.

## Supported versions

Detour is under active development. Security fixes are applied to the current
default branch and the currently deployed mobile, admin, and marketing
versions. Older commits and unreleased builds are not supported.
